# sheep-face-continual-learning
Code for the paper: ‘Prototype-guided relation-preserving continual learning for sheep face identification across growth stages’.

## 📌 Overview

This repository provides the implementation of the proposed framework for continual sheep face identification across growth stages. The framework consists of:

- CGSFNet: a cross-growth-stage sheep face network for multi-scale identity representation.
- PGR-CL: a prototype-guided relation-preserving continual learning method for sequential model updating across T₁–T₄.

The code supports stage-wise training, continual updating, and historical-stage evaluation.

## 📂 Dataset

- Data source: 180 Small-tailed Han sheep, 1–12 months of age, 72,000 facial images.
- Data availability: The dataset is ‘not publicly available’ at present because its release is restricted by the data-sharing agreement with the participating farm. The dataset will be considered for public release after the agreement expires. Requests for research access may be directed to the corresponding author and will be considered subject to authorization from the farm and applicable institutional requirements.
